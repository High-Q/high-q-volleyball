## ADDED Requirements

### Requirement: 一覧からの複製アクションの遷移

`apps/admin` の `/events` 一覧の各行の複製アクションは、押下時に当該行のイベントを複製元として新規作成画面 `/events/new?from=<eventId>` へ遷移する MUST。複製アクションは複製元の `events` 行に対して UPDATE / DELETE を一切行わない MUST NOT（複製は新規作成の準備にすぎない）。

#### Scenario: 複製アクションからの遷移
- **WHEN** ユーザーが一覧のある行の「複製」を押下する
- **THEN** router が `/events/new?from=<その行の events.id>` に push され、新規作成画面が複製元を下敷きにした状態で開く

#### Scenario: 複製は複製元を変更しない
- **WHEN** ユーザーが複製を起点に新規作成して保存する
- **THEN** 新しい events 行が 1 件 INSERT され、複製元の events 行（name / start_at / end_at / venue_id / fee 等）は変更されない

### Requirement: 複製元を下敷きにした作成フォームのシード

`/events/new?from=<eventId>` で新規作成画面を開いたとき、システムは複製元イベントの **会場 / 開始時刻 / 終了時刻 / 参加費** を引き継いだ状態で作成フォーム（`mode='create'`）を描画する SHALL。**開催日は引き継がず空のまま**にする MUST（複製は別日の新規開催を作る操作のため、日付は必ず選び直させる）。

`from` クエリを伴わない従来の `/events/new` は、本変更による挙動変化を受けない MUST（純粋な追加）。

#### Scenario: 引き継ぎ項目のシード
- **WHEN** 会場・開始終了時刻・参加費が設定された複製元を指定して `/events/new?from=<id>` を開く
- **THEN** フォームの会場 / 開始時刻 / 終了時刻 / 参加費が複製元の値で初期化される

#### Scenario: 開催日は空のままシードされる
- **WHEN** `/events/new?from=<id>` を開く
- **THEN** 開催日欄は空で表示され、未入力のまま保存しようとすると開催日の必須バリデーションで送信が止まる

#### Scenario: from 無しの新規作成は従来どおり
- **WHEN** `/events/new`（`from` クエリなし）を開く
- **THEN** 既存の空フォーム（開始 18:00 / 終了 20:00 の既定値、vol 番号プレースホルダ提案）がそのまま描画され、複製シードは適用されない

### Requirement: 連番タイトルの自動採番

複製元のタイトルが定例イベントの連番形式（語尾が `vol.<数字>`）の場合、システムはタイトルの初期値に events 全体の最大 vol 番号 + 1 を採番した名称を入れる SHALL。連番形式でない複製元の場合はタイトルをそのまま引き継ぐ SHALL。採番に必要な番号の取得に失敗した場合は複製元タイトルをそのまま用い、フォーム全体を Error 状態にしない MUST。

#### Scenario: 連番タイトルの次番号採番
- **WHEN** タイトルが連番形式のイベントを複製元に開き、events 全体の最大 vol 番号が NN である
- **THEN** タイトル欄の初期値が `vol.<NN+1>` を含む名称になる（複製元の番号 + 1 ではなく、全体最大 + 1）

#### Scenario: 連番形式でないタイトルはそのまま引き継ぐ
- **WHEN** タイトルが連番形式でないイベントを複製元に開く
- **THEN** タイトル欄の初期値が複製元のタイトルそのままになる

#### Scenario: 採番取得失敗時の縮退
- **WHEN** 連番番号の取得クエリが失敗する
- **THEN** タイトル欄には複製元タイトルがそのまま入り、フォーム全体は Error にならず作成を続行できる

### Requirement: 複製元取得の状態表示とフォールバック

`from` クエリ指定時、システムは複製元イベントの取得状態に応じて以下を表示し分ける SHALL:

- **取得中**: 複製元取得の Loading を表示する。
- **取得成功**: 複製シードを適用し、複製元を下敷きに作成中であることが分かる手がかり（複製元イベント名を含む）をフォーム上部に表示する。
- **取得失敗**（該当 id なし / RLS で取得不可 / 通信失敗）: 複製シードを適用せず、通常の空フォームにフォールバックして作成を継続できるようにする MUST（複製は利便機能であり、取得失敗で作成自体を止めない）。

複製元の閲覧可否は既存の RLS に委ね、本機能で新たな読み取り経路を追加しない MUST NOT。

#### Scenario: 取得成功で手がかりを表示
- **WHEN** 有効な `from` を指定して作成画面を開き、複製元の取得に成功する
- **THEN** 複製シードが適用され、複製元イベント名を含む「複製して作成中」の手がかりがフォーム上部に表示される

#### Scenario: 取得失敗で空フォームにフォールバック
- **WHEN** 存在しない / 閲覧権限のない id を `from` に指定して作成画面を開く
- **THEN** 複製シードは適用されず、通常の空フォームが描画され、そのまま新規作成を続行できる
