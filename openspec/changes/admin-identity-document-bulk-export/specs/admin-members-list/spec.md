## ADDED Requirements

### Requirement: 会員選択チェックボックス列

`/members` 画面は MUST 既存 7 列の左側に**選択チェックボックス列**を追加する SHALL。デスクトップの DataTable とモバイルのカード縦積みの両方で各会員行に選択チェックボックスを表示する。

- ヘッダ（デスクトップ）には「現ページ全選択」チェックボックスを置き、現ページの一部のみ選択時は MUST indeterminate 状態を表示する SHALL。
- 選択状態は MUST `Set<MemberId>` として保持し、**ページ送り / フィルタ変更をまたいでも維持**する SHALL。
- `has_identity_document === false`（本人確認書類を 1 件も持たない）会員のチェックボックスは MUST disabled とする SHALL（取り出す対象が無いため）。
- 既存の「名前 / メール / 経験 / 初回参加 / 累計 / 最終参加 / メモ」7 列・固定ソート / フィルタ / ページネーション・行クリックでの詳細 sheet 起動は MUST 維持する SHALL。

#### Scenario: 選択列の追加
- **WHEN** Success 状態で `/members` を描画する
- **THEN** 既存 7 列の左に選択チェックボックス列が表示され、各会員行にチェックボックスが表示される

#### Scenario: 現ページ全選択と indeterminate
- **WHEN** ヘッダの全選択チェックボックスを押す
- **THEN** 現ページの選択可能な会員がすべて選択される。一部のみ選択されている状態ではヘッダのチェックボックスは indeterminate で表示される

#### Scenario: ページをまたいだ選択保持
- **WHEN** ページ 1 で 2 名を選択してページ 2 へ移動し、ページ 1 へ戻る
- **THEN** ページ 1 で選択した 2 名の選択状態が維持されている

#### Scenario: 書類未提出会員は選択不可
- **WHEN** `has_identity_document === false` の会員行を描画する
- **THEN** その行のチェックボックスは disabled で、選択できない

### Requirement: チェックボックス操作と行クリックの分離

選択チェックボックスの操作は MUST 行クリック（詳細 sheet 起動）と衝突させない SHALL。チェックボックス領域のクリックは MUST イベント伝播を止め、詳細 sheet を開かない SHALL。チェックボックス以外のセルのクリックは従来どおり詳細 sheet を開く。

#### Scenario: チェックボックスクリックで sheet が開かない
- **WHEN** 会員行のチェックボックスをクリックする
- **THEN** その会員の選択状態がトグルされ、詳細 sheet は開かない

#### Scenario: 行本体クリックで従来どおり sheet が開く
- **WHEN** チェックボックス以外のセルをクリックする
- **THEN** 従来どおり当該会員の詳細 sheet が開く

### Requirement: 一括アクションツールバー

`/members` 画面は MUST 1 件以上の会員が選択されているときに**一括アクションツールバー**を表示する SHALL。ツールバーは「選択件数」「会員名簿と本人確認書類をダウンロード」ボタン「選択を解除」操作を含む。選択 0 件のときはツールバーを MUST 表示しない SHALL。

ダウンロードボタン押下時は MUST `admin-identity-document-export` capability の**エクスポート準備ダイアログ**を起点として開く SHALL。住所 / 電話番号の入力、承認済み抽出、CSV / PDF / ZIP 生成、監査ログ、進捗・部分失敗の具体挙動は `admin-identity-document-export` capability に定義する。

#### Scenario: 選択時にツールバー表示
- **WHEN** 3 名の会員を選択する
- **THEN** 一括アクションツールバーが表示され、「3 名選択中」相当の件数とダウンロードボタン・解除操作が表示される

#### Scenario: ダウンロード起動で準備ダイアログが開く
- **WHEN** ツールバーの「会員名簿と本人確認書類をダウンロード」を押す
- **THEN** エクスポート準備ダイアログが開き、選択会員の住所 / 電話番号の入力・確認に進む

#### Scenario: 全解除でツールバー非表示
- **WHEN** 「選択を解除」を押す
- **THEN** 選択が 0 件になり、一括アクションツールバーが非表示になる
