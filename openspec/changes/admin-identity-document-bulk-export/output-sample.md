# 出力物サンプル — 本人確認書類一括ダウンロード（#172）

> Apply 前イメージ共有用。実装確定ではなく「こういう物が出る」の目安。
> 氏名・住所・電話番号・会員 id はすべてダミー。

---

## 1. ダウンロードされる ZIP の中身

選択会員（例: 田中 / 佐藤 / 鈴木 の 3 名）を一括ダウンロードすると、**1 つの ZIP** が admin のローカルに保存される。

```
役所提出_20261102.zip
├── 会員名簿.csv          ← 江東区フォーマット（全選択会員）
└── 本人確認書類.pdf       ← 承認済み書類のある会員のみページ化
```

（ZIP 名の日付や区切りは実装時に最終決定）

---

## 2. 会員名簿.csv（江東区フォーマット + 年齢列）

- 列は **氏名 / 住所 / 年齢 / 電話番号** の 4 列（役職名列は出力しない）
- UTF-8 BOM 付き（Excel で日本語が化けない）
- **選択した全会員**を載せる（承認済み書類が無い人も名簿には載る）
- 氏名 = `姓 + ' ' + 名`（本名） / **住所 = 空欄（アプリは出力しない。エクスポート後にオーナーが PDF と突合して補記）** / **年齢 = 生年月日からエクスポート日時点で自動計算（入力不要）** / 電話 = DB 値をそのまま出力（アプリ上で編集しない）

Excel で開いたときの見え方（アプリ出力直後・エクスポート日 2026-11-02）:

| 氏名 | 住所 | 年齢 | 電話番号 |
|------|------|------|----------|
| 田中 太郎 |  | 42 | 090-1234-5678 |
| 佐藤 花子 |  | 35 | 080-2222-3333 |
| 鈴木 一郎 |  | 28 |  |

※ **住所列はアプリ出力時点では全行空欄**。この ZIP の PDF（書類画像）と CSV を Claude に渡し、画像の住所を読んで住所列に補記してもらう運用。
※ 年齢は会員登録時の生年月日（必須収集済み）から自動算出。admin は入力しません。
※ 3 行目の鈴木さんは電話番号が DB で NULL → **空欄**で出力。

生の CSV テキスト（アプリ出力直後。先頭にある見えない BOM を `<BOM>` と表記）:

```csv
<BOM>氏名,住所,年齢,電話番号
田中 太郎,,42,090-1234-5678
佐藤 花子,,35,080-2222-3333
鈴木 一郎,,28,
```

エクスポート後に Claude が住所を補記した状態（例）:

```csv
<BOM>氏名,住所,年齢,電話番号
田中 太郎,東京都江東区豊洲1-2-3,42,090-1234-5678
佐藤 花子,"東京都江東区東陽4-5-6 ○○マンション201",35,080-2222-3333
鈴木 一郎,東京都江東区亀戸7-8-9,28,
```

※ 住所に `,` や空白が含まれる場合は `"..."` で囲むエスケープが入る（2 行目イメージ）。

## 3. 本人確認書類.pdf（1 ファイル集約）

- **承認済み（approved）書類の画像のみ**を 1 つの PDF に集約
- 承認済み書類 1 件 = 1 ページ。各ページ上部に **ASCII ラベル（通し番号 + 英語書類種別）のみ**
- **氏名などの日本語テキストはページに描画しない**（pdf-lib 標準フォントが日本語非対応のため）。氏名は書類画像そのものに写っているので、後で住所を補記する際にレムが画像から氏名を読んで CSV 行に対応づける
- 表面 → 裏面の順に画像を配置（裏面が無ければ表面のみ）
- 1 会員が複数の承認済み書類を持つ場合はページを分ける
- ページは CSV の会員行順に並べる。承認済み書類ゼロの会員（例: 鈴木さん）は **PDF にページを作らない**（CSV には載る）

### ページ構成の例（田中さんは免許証・佐藤さんはマイナンバーカード〈マスク済み〉を提出）

```
┌─────────────────────────────┐  ┌─────────────────────────────┐
│ No.1  drivers_license        │  │ No.2  my_number_card_masked  │
│                             │  │                             │
│ ┌─────────────────────────┐ │  │ ┌─────────────────────────┐ │
│ │                         │ │  │ │                         │ │
│ │   [ 表面画像 (氏名入り) ] │ │  │ │   [ 表面画像 (氏名入り) ] │ │
│ │                         │ │  │ │   （個人番号マスク済み）  │ │
│ └─────────────────────────┘ │  │ └─────────────────────────┘ │
│ ┌─────────────────────────┐ │  │                             │
│ │                         │ │  │   ※裏面なし（表面のみ）       │
│ │     [ 裏面画像 ]         │ │  │                             │
│ │                         │ │  │                             │
│ └─────────────────────────┘ │  │                             │
└─────────────────────────────┘  └─────────────────────────────┘
   1 ページ目（CSV 1 行目=田中）    2 ページ目（CSV 2 行目=佐藤）

  （鈴木さんは承認済み書類ゼロ → PDF にページなし。結果ダイアログで通知）
```

- ラベルは ASCII のみ。氏名は画像内に写るため突合に困らない
- jpg / png が混在していても、拡張子・マジックバイトで判定して両方埋め込む
- 取得に失敗した画像は PDF から抜け、結果ダイアログに「取得失敗」として表示

## 4. ダウンロード後の結果ダイアログ（画面表示・ZIP の中身ではない）

ZIP 保存のあとに admin 画面へ出るサマリの例:

```
✅ ダウンロードが完了しました

 ・名簿に載せた会員:        3 名
 ・PDF に含めた書類:        2 件（田中 太郎 / 佐藤 花子）
 ・承認済み書類なし:        1 名（鈴木 一郎）  ← PDF 対象外
 ・取得に失敗した書類:      0 件

 監査ログに記録しました。
```

---

## 補足

- この CSV / PDF は **admin のローカル端末に保存されるだけ**（メール送付・クラウド共有なし＝SOP §3）
- 誰がいつ誰の書類を出したかは `identity_document_downloads` テーブルに監査記録として残る
