## Why

役所への団体登録（スポーツ団体登録 / 社会教育団体登録）の証憑として、江東区指定フォーマットの**会員名簿**と、会員の**本人確認書類**をまとめて提出する運用がある。MVP1 では admin が Supabase Dashboard 経由で書類画像を 1 件ずつ手作業ダウンロードし、名簿は別途手作業で作成しており非効率。会員一覧から複数会員を選び、江東区フォーマットの名簿 CSV と本人確認書類（1 ファイルに集約）を一括で取り出せるようにし、誰がいつ誰の書類を取り出したかを監査記録として残す。

参考: 江東区 登録団体 会員名簿様式（列: 役職名 / 氏名 / 住所 / 電話番号）。本機能では役職名を除く 氏名 / 住所 / 電話番号 を出力する。

## What Changes

- 会員一覧（`/members`）に**会員を複数選択**する仕組み（行チェックボックス + 現ページ全選択）を追加する。選択はページをまたいで保持する。
- 選択会員に対する**エクスポート準備ダイアログ**を追加する。江東区名簿に必要な **住所**（DB 未収集のため admin がその場で入力）と **電話番号**（DB 値をプリフィル・編集可）を会員ごとに確認・入力する。
- 一括ダウンロードで以下を含む **ZIP** をローカルに生成する:
  - **会員名簿.csv** — 江東区フォーマット（列: 氏名 / 住所 / 電話番号、役職名は含めない）。UTF-8 BOM 付き。
  - **本人確認書類.pdf** — 選択会員の**承認済み（approved）書類画像のみ**を 1 つの PDF に集約。会員ごとにページを分け、各ページに氏名ラベルを付け、表面 / 裏面を含める。
- approved 以外（pending / rejected）は対象外。承認済み書類が 0 件の会員は CSV には載せつつ PDF には書類が無い旨を結果サマリで通知する。
- 一括ダウンロードの**監査ログ**（誰が・いつ・どの会員 / どの書類を取り出したか）を専用テーブルに記録する。
- ネットワーク経由の外部送信は行わず、admin のローカル端末への保存に閉じる（SOP §3「窓口対面のみ」に整合）。サーバ側 Edge Function / `service_role` は使わず、既存の admin authenticated クライアント + RLS で完結させる。

## Capabilities

### New Capabilities
- `admin-identity-document-export`: 会員一覧での複数選択、エクスポート準備ダイアログ（住所 / 電話番号の入力・確認）、江東区フォーマット名簿 CSV と本人確認書類 PDF の生成・ZIP 化、進捗 / 部分失敗の取り扱い、ダウンロード監査ログの記録を規定する。

### Modified Capabilities
- `admin-members-list`: 一覧 DataTable / カードに選択チェックボックス列を追加し、行クリック（詳細 sheet 起動）と選択操作を両立させる要件、および選択時の一括アクション起点を追加する。
- `data-schema`: 監査ログ用テーブル `identity_document_downloads` を追加する。
- `rls-policies`: `identity_document_downloads` の RLS（admin のみ SELECT / INSERT、不変ログ）と 3 ロール GRANT を追加する。

## Impact

- **DB**: 新規テーブル 1 つ（`identity_document_downloads`）+ RLS + GRANT migration。既存テーブルの変更なし（住所は DB に保存せず CSV 生成時の admin 入力のみで扱う）。
- **依存追加**: クライアント側 ZIP 生成（`jszip` 等）+ PDF 生成（`pdf-lib` 等、jpg/png 画像を埋め込み可能）を `apps/admin` に追加。いずれもダウンロード実行時に dynamic import。
- **コード**: `apps/admin` の会員一覧 widget（選択列）、新規 feature（一括エクスポート: 選択・住所入力ダイアログ・CSV/PDF 生成・ZIP・監査ログ）、identity-document entity（承認済み書類の取得）、新規 entity（監査ログ）、`shared/ui` に Checkbox プリミティブを追加。
- **既存機能への影響**: 会員一覧の行クリック挙動・詳細 sheet・フィルタ / ソート / ページネーションは維持。本人確認書類レビュー画面（`/identity-documents`）は変更しない。
- **個人情報**: 住所は DB に保存せず、エクスポート時に admin が入力した値を CSV に書き出すのみ（収集項目を増やさない）。出力物は admin ローカルに閉じ、外部送信しない。
- **ドキュメント**: 本人確認書類取扱 SOP（§3 役所提出 / §5 監査ログ）を Sync 時に更新。
