# Proposal: レガシー LP AWS バックエンド退役

> **承認ゲート**: このドキュメントをレビューし、実装者と承認者が合意してから次フェーズへ進むこと。

## Why（なぜやるか）

- AWS Lambda の Python 3.10 ランタイムが **2026-10-31 に EOL**。対象 AWS アカウント（`ap-northeast-1`）に該当ランタイムの Lambda が 1 つ存在する（AWS Health 通知を受信済み）。
- その Lambda は **レガシー LP のイベント取得バックエンド**（API Gateway + Lambda + DynamoDB + 実行用 IAM role）の構成要素。LP のイベント取得は既に Supabase へ移行済み（archive: `2026-05-12-dynamodb-events-supabase-migration` / `2026-05-12-lp-events-supabase-migration`）で、現行リポジトリは AWS エンドポイントを一切参照していない。
- 放置すると、**未パッチ・サポート外のランタイム**が、2026-05 以降更新の止まった DynamoDB の古いイベントを、公開 URL への低頻度の外部アクセスに返し続ける構造が残る。費用ゼロ運用方針とも相容れない。
- 2026-10-24 に AWS 実調査を完了済み。ランタイム延命（Python 更新）は「死んだデータソースを延命する」構造が残るため不採用とし、**確認 → 退役**の方針で合意済み。

## What Changes（何が変わるか）

| 観点 | 変更前 | 変更後 |
|------|--------|--------|
| LP イベント取得バックエンド | レガシー AWS スタックが稼働（未使用だが公開 URL から叩ける） | 退役（存在しない） |
| Python 3.10 EOL リスク | 該当 Lambda あり | 解消（対象リソースが存在しない） |
| 調査用に一時作成した観測リソース | アクセスログ/ロール/アカウント設定が残存 | 撤去 |
| 退役前バックアップ | ローカルに取得済み | 保持（ロールバック元） |
| リポジトリのコード | AWS 参照ゼロ（現状維持） | 変更なし（docs に退役記録を追記するのみ） |

## Capabilities（実現できること）

- Python 3.10 EOL の影響を受けるリソースが AWS アカウントから消滅する。
- LP / events が Supabase 単一経路であることが、コードだけでなく**インフラ実体でも**担保される。
- 退役の経緯・バックアップ所在・ロールバック手順が docs に記録として残り、後任や将来の自分が追跡できる。

## Impact（影響範囲）

### 影響するコンポーネント・ファイル

- **AWS インフラ（リポジトリ外）**: レガシー LP スタックの中核リソース群 + 2026-10-24 の調査で一時作成した観測用リソース群（詳細な識別子は `tasks.md`）
- `docs/08-移行/`: 退役記録を新規ドキュメントとして追記
- `openspec/specs/lp-calendar`: 「AWS API Gateway 経路が残らない」要件を、コード参照だけでなく**インフラ実体の退役**まで含むよう強化

### 影響しない範囲（Non-Goals）

- 現行 LP / admin / reservation のランタイム動作（AWS 非参照のため無影響）
- Supabase 側の `events` / `venues` データ（一切変更しない）
- 一度きり移行スクリプト `scripts/migrate-aws-events-to-supabase.ts` 自体の削除（移行は完了済み。AWS 退役により実行不能になるが、本 Issue のスコープ外。必要なら別 Issue）

## 制約・前提条件

- **リポジトリ外の AWS 操作**。SSO ログイン（AdministratorAccess）は翔太郎くんが本物のターミナルで実施する（`!` 経由ではブラウザ認証・対話入力ができない）。削除コマンドの実行はレムが担う。
- アクセスログの保持は **7 日**（調査時 2026-10-24 に設定 → 約 2026-10-31 に失効）。呼び出し元の確認と削除は失効前に行う。
- 期限は **2026-10-31**（EOL 当日）。
- 退役は**不可逆**。削除の前提として「退役前バックアップ取得済み」＋「呼び出し元がボット/非本質であることの確認」の 2 点をゲートとする。
