## MODIFIED Requirements

### Requirement: 予約 Sheet のディープリンク起動 (再予約導線)

会員サイトはイベント詳細画面 (`event-detail`) に対し、**クエリパラメータによる予約 Sheet（create モード）の自動オープン** を SHALL 提供する。これは再予約導線（履歴の「再予約する」/ 完了画面の「やっぱり予約する」）および **LINE 告知の予約直行リンク**（admin の告知文に差し込まれるリンク）の共通着地点とする MUST。

イベント詳細画面はマウント時に所定の自動オープンクエリを検知し、**対象イベントが受付可能で、かつ会員本人に有効な予約が無いときに限り** create モードの予約 Sheet を自動オープンする MUST。受付可能の判定は新規予約と同一基準（`events.start_at > now()`（未開催）かつ 満席でない（`formatAvailability(availability).isFull === false`））とする MUST。会員本人の当該イベントの予約が予約済み（`reserved`）またはキャンセル待ち（`waitlist`）の場合は有効な予約ありとして自動オープンしない MUST（キャンセル済み（`cancelled`）は有効な予約に含めない）。本人の予約状態の取得が完了するまで判定を保留し、取得に失敗した場合は自動オープンしない MUST。受付不可（受付終了 / 満席）または有効な予約ありのときは Sheet を開かず、通常のイベント詳細（締切表示・予約状態表示を含む）を描画する MUST。

自動オープン後はブラウザ戻る操作等による再発火を防ぐため、当該クエリパラメータを履歴から除去する MUST（`router.replace` 相当でクエリを除く）。自動オープンしなかった場合も判定後に同様に除去する MUST。

LINE アプリに標準ブラウザで開かせるための付加クエリ（`openExternalBrowser`）は会員サイトでは意味を持たないため、イベント詳細画面への着地後に自動オープンクエリの有無にかかわらず URL から除去する MUST。

未ログインで自動オープンクエリ付きのイベント詳細に到達した場合、既存の `next` 引き継ぎによりクエリを保持したまま認証フローへ回し、認証完了後に同じイベント詳細へ戻って本要件の判定を行う MUST。

自動オープンで開いた Sheet の挙動（入力欄 / 合計金額 / localStorage 復元 / 確定経路 / 重複・再活性化処理）は通常の create モードと同一とする MUST。すなわち過去キャンセル済予約があれば確定時に既存行が再活性化される（「予約確認 Bottom Sheet」要件の create モード挙動に従う）。

#### Scenario: 受付可能イベントでの自動オープン
- **WHEN** 有効な予約を持たない会員が、受付可能（未開催かつ非満席）なイベントの詳細画面に自動オープンクエリ付きで遷移する
- **THEN** create モードの予約 Sheet が自動的に立ち上がる

#### Scenario: 受付不可イベントでは自動オープンしない
- **WHEN** 受付終了（開催済）または満席のイベントの詳細画面に自動オープンクエリ付きで遷移する
- **THEN** 予約 Sheet は開かず、通常のイベント詳細（締切表示）が描画される

#### Scenario: 予約済み会員には自動オープンしない
- **WHEN** 当該イベントを予約済み、またはキャンセル待ち登録済みの会員が自動オープンクエリ付きで詳細画面に遷移する
- **THEN** 予約 Sheet は開かず、通常のイベント詳細（本人の予約状態表示）が描画される

#### Scenario: 予約状態の取得失敗時は自動オープンしない
- **WHEN** 自動オープンクエリ付きで詳細画面に遷移し、会員本人の予約状態の取得に失敗する
- **THEN** 予約 Sheet は開かず、自動オープンクエリは URL から除去される

#### Scenario: 自動オープンクエリの除去
- **WHEN** 自動オープンクエリで予約 Sheet が開いた直後に URL を確認する
- **THEN** 自動オープンクエリは URL から除去されており、ブラウザ戻る操作で Sheet が再オープンされない

#### Scenario: LINE 用付加クエリの除去
- **WHEN** `openExternalBrowser=1` を含む URL でイベント詳細画面に着地する
- **THEN** `openExternalBrowser` は URL から除去され、それ以外のクエリ（自動オープン判定前の `book` を除く）は維持される

#### Scenario: 未ログインでの告知リンク着地
- **WHEN** 未ログインの利用者が `/events/<id>?book=1&openExternalBrowser=1` に到達し、ログインを完了する
- **THEN** 認証完了後に `/events/<id>` へ戻り、受付可能かつ有効な予約が無ければ予約 Sheet が自動オープンする

#### Scenario: 自動オープン経由でのキャンセル後再予約
- **WHEN** 過去キャンセル済予約 (`status='cancelled'`) を持つ会員が自動オープンで開いた create Sheet で予約を確定する
- **THEN** 既存行が `'reserved'` に再活性化され、完了画面へ遷移する（通常 create モードと同一の再活性化挙動）
