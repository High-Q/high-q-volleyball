## Why

Dependabot が多数の脆弱性アラートを出しているが、その大半はビルド・テスト・Lint など開発ツールチェーンの孫依存に閉じており、会員が触れる本番サイトや Edge Function のランタイムには一切載らない。とはいえアラートが積み上がると本当に危険なものが埋もれてノイズになるため、コード変更を伴わずに安全に潰せる分を先に片付けて、可視性を回復する。

## What Changes

- ルートの依存解決オーバーライド（`pnpm.overrides`）で、孫依存に閉じた脆弱パッケージ群を、現行メジャー系統の内側でパッチ版へ寄せる。
- lockfile を更新し、重複を整理する。
- アプリケーションコードは変更しない。ビルドとテストが緑であることを解消の受け入れ条件とする。
- ビルドツール本体（テストランナー / バンドラ）のメジャー更新は破壊的変更を含むため、本変更には**含めない**（後続の別変更で扱う）。
- バンドラの peer に固定された孫依存は、そのメジャー更新でしか安全に解消できないため、本変更のスコープから明示的に外す。

## Capabilities

### New Capabilities
（なし）

### Modified Capabilities
- `monorepo-workspace`: 孫依存に閉じたセキュリティ脆弱性を、ルートの依存解決オーバーライドで現行メジャー系統の内側でパッチ版へ寄せる保守方針を要件として追加する。

## Impact

- 変更ファイル: ルート `package.json`（`pnpm.overrides`）、`pnpm-lock.yaml`。
- 影響レイヤー: 開発ツールチェーンのみ。本番配信バンドル・Edge Function ランタイムへの影響なし。
- 検証: 全アプリのビルド、テストスイート、CI 全ジョブが緑であること。
- 関連: 後続変更（バンドラ／テストランナーのメジャー更新）が、本変更でスコープアウトした残りのアラートを解消する。
