## ADDED Requirements

### Requirement: モバイルでのページ全体スクロール

admin の認証配下の各ページは、モバイル（< `md`）で画面高さに固定した内側スクロール枠にコンテンツを閉じ込めては MUST NOT。ページ全体のスクロールで、上部の見出し・統計・タブ・ツールバー等に押し下げられた本文（一覧・詳細・フォーム）の全コンテンツへ到達できる SHALL。

デスクトップ（≥ `md`）は、ヘッダを固定し本文だけを内側スクロールさせる従来のレイアウトを採用して MAY。レスポンシブ規約どおり、いずれの幅でも横スクロールは MUST NOT 発生させる。

本要件はマスター・ディテール型（2 ペイン）ページにも適用し、モバイルでは各ペインの内容がページスクロールに乗る SHALL。

#### Scenario: モバイルで参加者一覧の最後の行に到達できる

- **WHEN** 画面幅 375px でイベント詳細を開き、参加者が画面内に収まりきらない件数ある
- **THEN** ページを下方向にスクロールすると参加者一覧の最後の行（チェックイン操作要素を含む）が表示・操作でき、本文が画面下の極小領域に潰れていない

#### Scenario: モバイルで一覧ページがコンテンツ分だけ縦に伸びる

- **WHEN** 画面幅 375px で一覧系ページ（イベント / 会員 / 本人確認書類）を開く
- **THEN** ページは画面高さに固定された内側スクロール枠ではなく、コンテンツの高さに応じて縦に伸び、ページ全体のスクロールで全項目に到達できる

#### Scenario: デスクトップは内側スクロールを維持する

- **WHEN** 画面幅 1280px で同じページを開く
- **THEN** ヘッダ（パンくず・タイトル）は固定され、本文だけが内側スクロールする従来の挙動が維持される

#### Scenario: マスター・ディテールもモバイルではページスクロールに乗る

- **WHEN** 画面幅 375px で会場マスタを開き、会場フォームを表示する
- **THEN** フォームの内容はページスクロールで最後（保存・削除アクション）まで到達でき、固定枠内のペインスクロールに閉じ込められない
