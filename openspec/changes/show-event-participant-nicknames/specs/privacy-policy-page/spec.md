## ADDED Requirements

### Requirement: 予約イベント内での nickname 表示の周知

`/privacy` ページ本文は、会員のニックネーム (`members.nickname`) が **同じ予約イベント内で他参加者に表示される** 運用を SHALL 明記する。「取得する個人情報の項目」「利用目的」「保管期間と退会後の処理」のいずれかのセクション (もしくは複数) に該当の記述を加える MUST。

記述には以下の要点を含む MUST:

- nickname を予約イベント内で他参加者に表示する旨
- 表示対象は「自分が予約しているイベントの他参加者」に限定され、不特定多数への公開ではないこと
- 本名 / メールアドレス / 電話番号 / 生年月日 / 経験レベル等の個人特定可能情報は他参加者に開示されないこと
- nickname を空欄にした場合 (`NULL`) は汎用表記 (例: 「参加メンバー」) で表示されること

具体的な技術用語 (RPC / RLS 等) は本文に SHALL NOT 含めない (`privacy-policy-page` capability の既存方針「具体実装の詳細は安全上の理由から非公開」と整合)。

#### Scenario: nickname 表示運用の記述
- **WHEN** `/privacy` ページ本文を確認する
- **THEN** 「ニックネームは予約イベント内で他参加者に表示される」旨と、「本名 / メール / 電話番号 等の個人情報は他参加者に開示されない」旨が含まれている

#### Scenario: 表示範囲の限定
- **WHEN** `/privacy` ページ本文を確認する
- **THEN** 表示範囲が「予約しているイベントの他参加者」に限定される旨が明示され、「全会員に公開」「公開ページに掲載」等の表現は含まれない

#### Scenario: nickname 空欄時の汎用表記
- **WHEN** `/privacy` ページ本文を確認する
- **THEN** nickname 未設定時の汎用表記運用 (例: 「参加メンバー」) について言及されている

#### Scenario: 技術用語の非掲載
- **WHEN** `/privacy` ページ本文を確認する
- **THEN** 「RPC」「RLS」「SECURITY DEFINER」等の技術用語は本文に含まれない
