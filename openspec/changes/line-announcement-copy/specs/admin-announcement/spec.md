## ADDED Requirements

### Requirement: 告知チャネル

admin は告知チャネルとして LINE（`line`）と X（`x`）の 2 つを扱い、チャネルごとに 1 つのテンプレートを持つ MUST。LINE は High Q を知っている参加者向け（オープンチャット）、X は High Q を知らない人向けの告知に用いる。

#### Scenario: チャネルごとのテンプレート
- **WHEN** admin が LINE と X のテンプレートをそれぞれ保存する
- **THEN** 2 つのテンプレートは独立して保存・取得される

### Requirement: 差し込み項目の展開規則

admin は告知テンプレート本文中の差し込み項目（`{` と `}` で囲んだ日本語名）を、対象イベントの情報で置き換えて告知文を生成 MUST する。差し込み項目と値は以下とする MUST:

| 差し込み項目 | 値 | 値が無いとき |
|---|---|---|
| `{イベント名}` | イベント名 | — |
| `{回号}` | `vol.<回号>` | 空文字 |
| `{日付}` | `M/D(曜)`（日本時間） | — |
| `{開始時刻}` | `HH:mm`（日本時間） | — |
| `{終了時刻}` | `HH:mm`（日本時間） | — |
| `{会場}` | 会場名 | 空文字 |
| `{参加費}` | 3 桁区切り + `円`（0 は `無料`）。会場既定額を引き継いだ値を用いる | `未定` |
| `{定員}` | `<定員>名` | 空文字 |
| `{予約リンク}` | 当該チャネルの「告知用予約リンク」 | — |
| `{紹介ページリンク}` | 「紹介ページリンク」 | — |

日時の整形は操作端末のタイムゾーンによらず日本時間（Asia/Tokyo）で行う MUST。上表に無い `{...}` は置き換えずにそのまま残す MUST。同じ差し込み項目が複数回現れた場合はすべて置き換える MUST。

#### Scenario: 全項目の展開
- **WHEN** イベント名「ゆる練」/ 回号 42 / 開始 2026-11-14 18:00 JST / 終了 20:00 JST / 会場「有明会場」/ 参加費 1000 / 定員 24 のイベントで、全差し込み項目を含むテンプレートを展開する
- **THEN** それぞれ「ゆる練」「vol.42」「11/14(土)」「18:00」「20:00」「有明会場」「1,000円」「24名」と予約リンク・紹介ページリンクに置き換わる

#### Scenario: 値が無い項目の展開
- **WHEN** 回号・会場・定員・参加費が未設定のイベントで展開する
- **THEN** `{回号}` `{会場}` `{定員}` は空文字、`{参加費}` は「未定」になる

#### Scenario: 参加費 0 円
- **WHEN** 参加費 0 のイベントで `{参加費}` を展開する
- **THEN** 「無料」になる

#### Scenario: 知らない差し込み項目は残す
- **WHEN** テンプレートに `{集合時刻}` が含まれる
- **THEN** `{集合時刻}` はそのまま告知文に残る

#### Scenario: 端末タイムゾーンに依存しない
- **WHEN** 端末のタイムゾーンが UTC の状態で 2026-11-14 18:00 JST 開始のイベントを展開する
- **THEN** `{日付}` は「11/14(土)」、`{開始時刻}` は「18:00」になる

### Requirement: 告知用予約リンク

admin は告知用予約リンクを `<予約サイトのベース URL>/events/<URL エンコードしたイベント ID>?book=1` の形で生成 MUST し、LINE チャネルでは LINE アプリ内でタップされた際に標準ブラウザで開かせる `openExternalBrowser=1` を付加 MUST する（X チャネルでは付加しない）。ベース URL は環境変数で上書き可能とし、未設定時は本番の予約サイトを用いる MUST。ベース URL 末尾のスラッシュの有無で結果が変わってはならない MUST。

#### Scenario: LINE 用リンク
- **WHEN** ベース URL `https://high-q-reservation.onrender.com/` でイベント ID `abc` の LINE 用リンクを生成する
- **THEN** `https://high-q-reservation.onrender.com/events/abc?book=1&openExternalBrowser=1` になる

#### Scenario: X 用リンク
- **WHEN** 同じ条件で X 用リンクを生成する
- **THEN** `https://high-q-reservation.onrender.com/events/abc?book=1` になる

#### Scenario: 環境変数未設定時は本番
- **WHEN** ベース URL の環境変数が未設定でリンクを生成する
- **THEN** 本番の予約サイトを指すリンクになる

### Requirement: 紹介ページリンク

admin は紹介ページリンクとして LP（サークル紹介サイト）のトップ URL を用いる MUST。LP のオリジンは環境変数で上書き可能とし、未設定時は本番の LP を用いる MUST。

#### Scenario: 紹介ページリンクの既定値
- **WHEN** LP オリジンの環境変数が未設定で `{紹介ページリンク}` を展開する
- **THEN** 本番の LP トップ URL になる

### Requirement: X の文字数カウント

admin は X チャネルの告知文・テンプレートについて、X の数え方による文字数を表示 MUST する。数え方は、URL（`http://` / `https://` で始まる連続文字列）を 1 つあたり 23、絵文字（書記素単位）を 2、Latin 等の 1 として数える文字（U+0000〜U+10FF / U+2000〜U+200D / U+2010〜U+201F / U+2032〜U+2037）を 1、それ以外（日本語等）を 2 とする MUST。上限 280 を超える場合は注意を表示 MUST する（保存・コピーは妨げない）。

#### Scenario: 日本語と URL の数え方
- **WHEN** 「あいう https://example.com/very/long/path」を数える
- **THEN** 6 + 1 + 23 = 30 になる

#### Scenario: 上限超過の注意
- **WHEN** X テンプレートを展開した告知文が 281 以上になる
- **THEN** 上限を超えている旨の注意が表示され、コピーは可能である

### Requirement: 告知文ダイアログ

admin のイベント詳細から開く告知文ダイアログは、LINE / X のチャネル切り替えを提供 MUST し（初期表示は LINE）、選択中チャネルのテンプレートを当該イベントで展開した告知文をプレビュー表示 MUST する。操作は以下を提供 MUST する: 「告知文をコピー」（展開済み告知文をクリップボードへ）/「予約リンクをコピー」（選択中チャネルの告知用予約リンク）/「紹介ページリンクをコピー」/「テンプレートを編集」（選択中チャネルの告知テンプレート画面へ遷移）/ 閉じる。X 選択時は X の文字数を表示 MUST する。

ダイアログは Loading（テンプレート取得中）/ Empty（テンプレート未登録）/ Error（取得失敗）/ Success（プレビュー表示）の 4 状態を描画 MUST する。Empty / Error のときもリンクのコピーは使用可能 MUST とし、Empty では告知テンプレート画面への導線、Error では再試行を表示 MUST する。

コピー成功時はトーストで通知 MUST する。クリップボードへの書き込みに失敗した場合はエラーを通知し、コピー対象の文字列を読み取り専用欄に表示して全選択状態にする MUST。

#### Scenario: 告知文のコピー
- **WHEN** テンプレート取得に成功したダイアログで「告知文をコピー」を押下する
- **THEN** 展開済み告知文がクリップボードに書き込まれ、完了トーストが表示される

#### Scenario: チャネル切り替え
- **WHEN** ダイアログで X に切り替える
- **THEN** X のテンプレートで展開した告知文と X の文字数が表示される

#### Scenario: リンクのコピー
- **WHEN** ダイアログで「予約リンクをコピー」または「紹介ページリンクをコピー」を押下する
- **THEN** 対応するリンクのみがクリップボードに書き込まれ、完了トーストが表示される

#### Scenario: テンプレート未登録
- **WHEN** 選択中チャネルのテンプレートが存在しない状態でダイアログを開く
- **THEN** 「告知テンプレートが未設定です」と告知テンプレート画面への導線が表示され、リンクのコピーは使用できる

#### Scenario: テンプレート取得失敗
- **WHEN** テンプレートの取得が失敗する
- **THEN** エラーメッセージと再試行が表示され、リンクのコピーは使用できる

#### Scenario: クリップボード書き込み失敗
- **WHEN** 「告知文をコピー」押下時にクリップボードへの書き込みが失敗する
- **THEN** エラーが通知され、告知文が読み取り専用欄に全選択状態で表示される

### Requirement: 告知テンプレート画面

admin は `/announcement-template` に告知テンプレート画面を提供 MUST する。画面は LINE / X のチャネル切り替え（URL クエリ `channel` と同期、既定は LINE）と、選択中チャネルのテンプレート本文の編集欄（`FormField` でラップ）、差し込み項目の一覧、サンプルのイベント情報で展開したプレビュー、保存操作、最終更新日時を表示 MUST する。

- 差し込み項目の一覧の各項目を押下すると、編集欄のカーソル位置にその差し込み項目を挿入 MUST する。
- プレビューは編集内容に追従して更新 MUST する。
- 本文が空、または 5,000 文字を超える場合は保存不可とし、エラーを表示 MUST する。残り文字数を表示 MUST する。
- X 選択時は、プレビューの X 文字数と上限 280 を表示し、超過時は注意を表示 MUST する（保存は妨げない）。
- 本文に「差し込み項目の展開規則」に無い `{...}` が含まれる場合は注意を表示 MUST する（保存は妨げない）。
- 保存成功時はトーストで通知し最終更新日時を更新 MUST する。保存失敗時はエラートーストを表示し、入力内容を保持 MUST する。
- テンプレート未登録時はチャネルの初期テンプレートを編集欄に入れた状態で表示し、保存で作成 MUST する。
- 画面は Loading / Empty / Error / Success の 4 状態を描画 MUST し、モバイル（< `md`）では編集欄・差し込み項目・プレビューを縦積みにする MUST。

#### Scenario: テンプレートの保存
- **WHEN** admin が本文を編集して保存する
- **THEN** 選択中チャネルの `announcement_templates` 行が更新され、完了トーストと新しい最終更新日時が表示される

#### Scenario: チャネル切り替え
- **WHEN** admin が X に切り替える
- **THEN** URL が `?channel=x` になり、X のテンプレートが編集欄に表示される

#### Scenario: 差し込み項目の挿入
- **WHEN** 編集欄のカーソルが文中にある状態で差し込み項目「{会場}」を押下する
- **THEN** カーソル位置に `{会場}` が挿入され、プレビューに会場名が反映される

#### Scenario: 空の本文は保存できない
- **WHEN** 本文を空にして保存しようとする
- **THEN** 保存されず、本文が必須である旨のエラーが表示される

#### Scenario: 知らない差し込み項目の注意
- **WHEN** 本文に `{集合時刻}` を含める
- **THEN** `{集合時刻}` は差し込み項目ではない旨の注意が表示され、保存は可能である

#### Scenario: 保存失敗時に入力を保持
- **WHEN** 保存が通信エラーで失敗する
- **THEN** エラートーストが表示され、編集欄の内容は失われない
