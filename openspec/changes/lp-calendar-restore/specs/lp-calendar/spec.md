## ADDED Requirements

### Requirement: カレンダーが月表示で表示される
LPの EventContents セクションに Vuetify 3 の VCalendar が月表示で表示されること。

#### Scenario: ページ読み込み時に当月カレンダーが表示される
- **WHEN** LPのページを開く
- **THEN** 当月のカレンダーが表示される

### Requirement: 月ナビゲーションが動作する
前月・次月・今月ボタンで表示月を変更できること。

#### Scenario: 次月ボタンで翌月に移動する
- **WHEN** 次月ボタン（`>`）をクリックする
- **THEN** カレンダーの表示が翌月に切り替わる

#### Scenario: 前月ボタンで前月に移動する
- **WHEN** 前月ボタン（`<`）をクリックする
- **THEN** カレンダーの表示が前月に切り替わる

#### Scenario: Todayボタンで当月に戻る
- **WHEN** Todayボタンをクリックする
- **THEN** カレンダーの表示が当月に戻る

### Requirement: APIからイベントを取得してカレンダーに表示する
AWS API Gateway からイベント一覧を取得し、カレンダー上に表示すること。

#### Scenario: イベントがカレンダー上に表示される
- **WHEN** APIレスポンスに1件以上のイベントが含まれる
- **THEN** 各イベントが対応する日付のカレンダーセル上に表示される

### Requirement: イベントクリックで詳細ダイアログが表示される
カレンダー上のイベントをクリックすると詳細情報がダイアログで表示されること。

#### Scenario: イベントをクリックするとダイアログが開く
- **WHEN** カレンダー上のイベントをクリックする
- **THEN** イベントの名前・開始時間・終了時間・場所が表示されたダイアログが開く
