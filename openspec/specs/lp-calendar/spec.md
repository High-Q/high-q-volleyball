## Requirements
### Requirement: 月ナビゲーションでカレンダー表示が切り替わる
カレンダーの「＜」「＞」ボタンを押すと、表示月が前月・翌月に切り替わらなければならない（SHALL）。
ヘッダーに表示される年月テキストも連動して更新されなければならない（SHALL）。

#### Scenario: 次月への移動
- **WHEN** ユーザーが「＞」ボタンをクリックした場合
- **THEN** カレンダーの表示が翌月に切り替わり、ヘッダーの年月テキストが翌月を示す

#### Scenario: 前月への移動
- **WHEN** ユーザーが「＜」ボタンをクリックした場合
- **THEN** カレンダーの表示が前月に切り替わり、ヘッダーの年月テキストが前月を示す

#### Scenario: 今日ボタン
- **WHEN** ユーザーが「今日」ボタンをクリックした場合
- **THEN** カレンダーが当月に戻る

### Requirement: イベントがカレンダー上に表示される
API から取得したイベントは、対応する日付のセルにイベントとして表示されなければならない（SHALL）。

#### Scenario: イベントの表示
- **WHEN** API からイベントデータが正常に取得された場合
- **THEN** 各イベントの開始日に対応するカレンダーセルにイベントタイトルが表示される

#### Scenario: イベントクリック
- **WHEN** ユーザーがカレンダー上のイベントをクリックした場合
- **THEN** イベント詳細（タイトル・開始時間・終了時間・場所）のダイアログが表示される

### Requirement: カレンダーが月表示で表示される
LPの EventContents セクションに Vuetify 3 の VCalendar が月表示で表示されなければならない（SHALL）。

#### Scenario: ページ読み込み時に当月カレンダーが表示される
- **WHEN** LPのページを開く
- **THEN** 当月のカレンダーが表示される

### Requirement: 月ナビゲーションが動作する
前月・次月・今月ボタンで表示月を変更できなければならない（SHALL）。

#### Scenario: 次月ボタンで翌月に移動する
- **WHEN** 次月ボタン（`>`）をクリックする
- **THEN** カレンダーの表示が翌月に切り替わる

#### Scenario: 前月ボタンで前月に移動する
- **WHEN** 前月ボタン（`<`）をクリックする
- **THEN** カレンダーの表示が前月に切り替わる

#### Scenario: Todayボタンで当月に戻る
- **WHEN** Todayボタンをクリックする
- **THEN** カレンダーの表示が当月に戻る

### Requirement: APIからイベントを取得してカレンダーに表示する
AWS API Gateway からイベント一覧を取得し、カレンダー上に表示しなければならない（SHALL）。

#### Scenario: イベントがカレンダー上に表示される
- **WHEN** APIレスポンスに1件以上のイベントが含まれる
- **THEN** 各イベントが対応する日付のカレンダーセル上に表示される

### Requirement: イベントクリックで詳細ダイアログが表示される
カレンダー上のイベントをクリックすると詳細情報がダイアログで表示されなければならない（SHALL）。

#### Scenario: イベントをクリックするとダイアログが開く
- **WHEN** カレンダー上のイベントをクリックする
- **THEN** イベントの名前・開始時間・終了時間・場所が表示されたダイアログが開く
