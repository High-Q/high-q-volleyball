# ADR-0001: モノレポ構成の採用

- **日付**: 2026-04-24
- **状態**: 承認済み

## 背景

LP（既存）・管理画面・予約サイトの3アプリを開発する。Vuetifyテーマ・共通型・共通コンポーザブルを複数アプリで共有する必要がある。

## 決定

pnpm workspaces を使ったモノレポ構成を採用する。

```
apps/lp
apps/admin
apps/reservation
packages/shared
```

## 理由

- Vuetify テーマ・OpenAPI 生成型を `packages/shared` で一元管理できる
- CI/CD パイプラインを一箇所で管理できる
- 個人開発のため複数リポジトリを横断する運用コストを避けたい

## 却下した代替案

- **別リポジトリ管理**: 共通コードの同期が煩雑。CI設定が分散する。
