## デザイントークン（Design Tokens）

マジックナンバー（ハードコードされた色・サイズ値）の使用を禁止する。
すべてのトークンは Vuetify テーマまたは Tailwind `theme.extend` で一元管理する。

### カラーパレット

| トークン名 | 値 | 用途 |
|------------|-----|------|
| `primary` | `#182F43` | ナビゲーション・見出し・強調テキスト |
| `secondary` | `#85BBCC` | アクセント・アイコン・バッジ |
| `background` | `#FFFFFF` | ページ背景 |
| `surface` | `#F8F9FA` | カード・シート背景 |
| `error` | `#D32F2F` | エラー表示 |
| `success` | `#2E7D32` | 成功フィードバック |
| `warning` | `#F57C00` | 警告メッセージ |

### タイポグラフィ

| レベル | 用途 | フォントサイズ | ウェイト |
|--------|------|--------------|---------|
| `h1` / `section-title` | セクション見出し | 1.75rem | 900 |
| `h2` / `card-title` | カード・モーダル見出し | 1.25rem | 700 |
| `body` | 本文 | 1rem | 400 |
| `caption` | 補足情報・ラベル | 0.75rem | 400 |

### スペーシング（8pt グリッド）

```css
--space-1: 4px;
--space-2: 8px;
--space-3: 12px;
--space-4: 16px;
--space-6: 24px;
--space-8: 32px;
--space-14: 56px;  /* セクション間余白 */
```

### 使用例

```vue
<!-- ✅ Good: トークンを使用 -->
<v-btn color="primary">確認</v-btn>
<div class="section-title">EVENT</div>

<!-- ❌ Bad: マジックナンバー -->
<v-btn style="background-color: #182F43">確認</v-btn>
<div style="font-size: 1.75rem; color: #182F43">EVENT</div>
```

## コンポーネント設計原則

### 階層と責務分離

```
pages/         ← ルーティング単位。データ取得・composable 呼び出しのみ
  EventPage.vue
components/    ← 表示に特化。props で制御し、副作用を持たない
  EventCard.vue         ← 単一イベントの表示
  EventCardSkeleton.vue ← ローディング時のプレースホルダー
  EventList.vue         ← EventCard のリスト管理
composables/   ← アプリケーションロジック・状態管理
  useEvents.ts          ← イベント取得・状態
services/      ← 外部API・Supabase との通信のみ
  eventService.ts
```

### コンポーネント設計ルール

1. **1 コンポーネント = 1 責務**。表示ロジックと取得ロジックを混在させない。
2. **Props は読み取り専用**。コンポーネント内で props を変更しない（emit で親に伝える）。
3. **内部状態を最小化する**。`v-model` や `ref` は本当に必要な場合だけ使う。
4. **ビジネスロジックをコンポーネントに書かない**。composable または service に置く。

```vue
<!-- ✅ Good: 表示のみに集中したコンポーネント -->
<script setup lang="ts">
defineProps<{ event: EventSummary }>();
const emit = defineEmits<{ click: [id: string] }>();
</script>

<!-- ❌ Bad: コンポーネント内でAPIを呼ぶ -->
<script setup lang="ts">
const events = await supabase.from('events').select('*'); // NG
</script>
```

### Composable 設計ルール

```typescript
// ✅ Good: 明確な責務・Result型でエラーを表現
export function useEvents() {
  const events = ref<Event[]>([]);
  const isLoading = ref(false);
  const error = ref<string | null>(null);

  async function fetchEvents(): Promise<void> {
    isLoading.value = true;
    const result = await eventService.getAll();
    if (result.ok) {
      events.value = result.data;
    } else {
      error.value = result.error.message;
    }
    isLoading.value = false;
  }

  return { events: readonly(events), isLoading: readonly(isLoading), error: readonly(error), fetchEvents };
}
```

## 状態設計（必須の4状態）

すべてのデータ取得 UI は以下の4状態を必ず実装する。

| 状態 | 条件 | 表示 |
|------|------|------|
| **Loading** | `isLoading === true` | スケルトンスクリーンまたはスピナー |
| **Empty** | `items.length === 0` | 「データがありません」などの案内 |
| **Error** | `error !== null` | ユーザー向けメッセージ（技術詳細は非表示） |
| **Success** | データあり・エラーなし | 通常表示 |

```vue
<template>
  <div v-if="isLoading">
    <EventCardSkeleton v-for="i in 3" :key="i" />
  </div>
  <v-alert v-else-if="error" type="error">{{ error }}</v-alert>
  <div v-else-if="events.length === 0" class="empty-state">
    予定されているイベントはありません
  </div>
  <EventList v-else :events="events" />
</template>
```

## レスポンシブデザイン

### ブレークポイント（Vuetify / Tailwind 共通）

| 名前 | 幅 | 対象デバイス |
|------|-----|------------|
| `xs` | 〜599px | スマートフォン（縦） |
| `sm` | 600〜959px | スマートフォン（横）・タブレット（縦） |
| `md` | 960〜1279px | タブレット（横）・小型デスクトップ |
| `lg` | 1280px〜 | デスクトップ |

### モバイルファースト

- スタイルはモバイル（375px〜）を基本とし、`sm` 以上でレイアウトを拡張する
- タッチターゲット最小サイズ: **44×44px**（iOS HIG 準拠）
- テキストサイズはモバイルで `body: 16px` を下回らない

## アクセシビリティ（a11y）

### 必須要件

- **コントラスト比**: テキスト AA（4.5:1）以上
- **インタラクティブ要素**: すべてキーボードで操作可能
- **画像**: 装飾以外は `alt` 属性を必ず設定
- **フォーム**: `label` と `input` を紐付ける（`for` / `aria-labelledby`）
- **モーダル**: 開いた際にフォーカスをモーダル内に移動し、ESC キーで閉じる
- **エラーメッセージ**: `role="alert"` または `aria-live="polite"` で通知

```vue
<!-- ✅ Good -->
<v-btn aria-label="イベントを閉じる" icon @click="close">
  <v-icon>mdi-close</v-icon>
</v-btn>

<!-- ❌ Bad: アイコンのみでラベルなし -->
<v-btn icon @click="close"><v-icon>mdi-close</v-icon></v-btn>
```

## フォームデザイン方針

- **バリデーションはリアルタイム**（blur 時 + submit 時の二重チェック）
- **エラーメッセージはフィールド直下**に表示（ページ上部への集約はしない）
- **送信ボタンは処理中に disabled + ローディング表示**
- **成功フィードバックは `v-snackbar`** でトースト通知（3秒で自動消去）

---

## アニメーション・トランジション方針

- ページ遷移: `v-fade-transition`（100ms）
- リスト追加・削除: `v-slide-y-transition`
- モーダル開閉: Vuetify の `v-dialog` デフォルトトランジション
- `prefers-reduced-motion: reduce` を尊重し、過剰なアニメーションを無効化

```css
@media (prefers-reduced-motion: reduce) {
  * { animation-duration: 0.01ms !important; transition-duration: 0.01ms !important; }
}
```
