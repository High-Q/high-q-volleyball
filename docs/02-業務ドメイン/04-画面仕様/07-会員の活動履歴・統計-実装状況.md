## 実装済み機能

### 1. プロフィール画面 STATS（集計サマリ）
`/profile` の STATS セクション。会員ごとに集計して表示。

| 指標 | 内容 |
|---|---|
| 累計参加回数 | `status='attended'` の予約数（0回なら「—」） |
| 最終参加日 | attended の中で最新のイベント開催日 |
| 次回予定 | reserved かつ未来で最早のイベント（日付＋イベント名） |

- 実装: `apps/reservation/src/features/profile-stats/`（`lib/computeStats.ts` / `ui/StatsSection.vue`）
- spec: `openspec/specs/reservation-profile-page/spec.md` L230-260
- 実装履歴: `openspec/changes/archive/2026-05-06-reservation-profile-page`（tasks 4.1-4.7 全完了）
- PR #210（#91 として 2026-05-06 クローズ済み）

### 2. `/history` 画面（活動履歴一覧）
自分の予約・参加の履歴を時系列で閲覧。

- **サマリ Strip（3 カード）**: **TOTAL**（累計参加）/ **NEXT**（次回予定 MM/DD）/ **STREAK**（連続参加）
- **予約中グループ**: これから参加する予約。各行に**キャンセル動線**付き
- **過去グループ**: 参加済・キャンセル済の履歴
- **各行の表示**: イベント名・開催日時・会場名・ステータス（予約中／参加済／キャンセル済）
- **状態対応**: Loading（スケルトン）／ Empty（「まだ予約がありません」＋導線）／ Error（再試行）／ Success（トースト）を完備
- 実装: `apps/reservation/src/pages/HistoryPage.vue` / `widgets/history-stats-strip/` / `features/history-list/`
- 実装履歴: `openspec/changes/archive/2026-05-06-reservation-reservation-history-page`
